# PokeRPG

Godot 4 vertical/mobile prototype for the initial PokeRPG flow.

## Project Layout

- `scenes/`: Godot scenes.
- `scripts/`: GDScript game/UI logic.
- `scripts/tools/`: local utility scripts, including single GIF conversion tools.
- `assets/`: runtime assets used by the game.
- `assets/pokemon/`: prepared future structure for Pokemon icons and animated battle frames.
- `data/`: generated manifests and lightweight game data.
- `web/`: browser-only HTML preview for quick UI testing.
- `archives/`: source archives kept for reference.

Large raw asset zips are kept locally in `archives/raw_asset_zips/` and ignored by Git because they are not runtime assets and may exceed GitHub file limits.
